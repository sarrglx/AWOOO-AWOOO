# Página romántica

## Personalizar

Abre `script.js` con un editor de texto. En la sección `PERSONALIZA AQUÍ` cambia:

- `girlfriendName`: su nombre o apodo.
- `userName`: cómo quieres firmar.
- `relationshipStart`: la fecha y hora en que inició la relación.
- `letter`, `reasons` y `finalMessage`: los textos personales.

La música es opcional. Para usarla, coloca un archivo llamado `music.mp3` en esta misma carpeta. Comparte únicamente música que tengas derecho a publicar.

## Probarla

Haz doble clic en `index.html`. Se abrirá en el navegador; desde ahí también puedes usar la vista de teléfono del navegador para revisarla.

## Publicarla y obtener un enlace

Una opción simple y gratuita es **GitHub Pages**:

1. Crea una cuenta en GitHub si todavía no tienes una.
2. Crea un repositorio nuevo, por ejemplo `para-mi-amor`, y súbelo con los cuatro archivos de esta carpeta (y `music.mp3`, si lo usas).
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/(root)`, luego guarda.
5. GitHub mostrará un enlace `https://tu-usuario.github.io/para-mi-amor/`. Ese es el que puedes enviarle y funciona desde su teléfono.

También puedes arrastrar esta carpeta a Netlify Drop (app.netlify.com/drop); te dará un enlace público en unos segundos.
